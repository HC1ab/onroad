# E-server 구역 규칙

범위: F15 읽기 전용 API(FastAPI), F16 Ubuntu 배포(Docker Compose, Nginx), DB 적재, F18 정적 폴백 내보내기.

- API는 읽기 전용이다. POST·PUT·DELETE 등 쓰기 경로를 만들지 않는다. 요청 시 계산하지 않고 파이프라인이 만든 결과 테이블만 조회한다.
- 서버와 DB 컨테이너에 원본 데이터(`data/raw/`)와 공공데이터 인증키를 두지 않는다. 적재하는 것은 결과 테이블뿐이다.
- 로컬과 서버는 같은 Docker 이미지를 쓴다. 차이는 `.env.local`/`.env.prod` 값(DB 접속 정보, 허용 주소)으로만 둔다. 저장소에는 `.env.example`만 올린다.
- DB(:5432)는 외부에 열지 않는다. 비밀번호는 `.env`에만 둔다(CLAUDE.md R3).
- `adm_cd`는 문자열, 좌표는 EPSG:4326. 응답 스키마는 `../contracts/`와 일치해야 한다.
- 오류 응답에 내부 경로·쿼리·스택 트레이스를 노출하지 않는다.
- 응답에 쓰는 문구는 PRD 3장 표현 원칙을 따른다("점검 우선순위 후보", "기록값이 기준식보다 짧음").
- 로컬 실행: `docker compose up` (DB와 API). 프론트는 `/api`를 :8000으로 프록시한다.
