# B-validation 구역 규칙

범위: V1 현장 실측, V2 속도 민감도, V3 사고다발지역 연관성(연도 분할), V4 축 독립성·"이미 조정됐는가", V5(선택) 보정 연관성. 출력은 `validation.json`.

- **결과가 기대와 달라도 그대로 보고한다.** 좋은 쪽만 고르지 않는다.
- 연관성까지만 말한다. 인과 표현("~ 때문에", "늘리면 줄어든다") 금지.
- V1 측정은 인도에서만 한다. 차도에 들어가지 않는다. 사진은 repo에 올리지 않는다(`field/photos/` gitignore).
- 점멸 구간은 분리 기록한다(`measured_green_s`, `measured_flash_s`). 이 결과가 녹색신호시간 필드 정의를 확정한다.
- 사고 데이터는 연도 분할: 과거 연도 = 노출 플래그, 최근 연도 = 확인용. 같은 데이터로 고르고 검증하지 않는다.
