# 공공데이터 수집 가이드 — 한 박자(횡단보도) 팀원용

Oct 23, 2026 · @SH

팀원이 할 일은 표의 데이터를 내려받아 원본 그대로 보관하고, 데이터별로 확인 항목을 채워 SH에게 알려 주는 것이다. 분석은 이 문서 범위 밖이고, 아직 아무도 실제 파일을 내려받아 보지 않았으므로(데이터 페이지만 확인함) 확인 항목의 답이 프로젝트의 성립 여부를 정한다.

## 1. 개요와 저장 규칙

**목적:** 전국 횡단보도의 녹색신호시간을 기준식(7 + 연장/속도)과 비교하고 고령 인구·목적지·사고 데이터와 겹쳐 점검 후보를 찾는 프로젝트다. 아래 데이터가 그 재료다. 세부 기획은 PRD에 있다.

**원본 보관 규칙**

- 내려받은 파일은 절대 수정·저장하지 않는다(엑셀로 열어 다시 저장하면 인코딩과 숫자 형식이 바뀔 수 있다). 확인은 복사본으로 한다.
- 파일명은 원본 그대로 두고, 폴더로 구분한다.
- `data/raw/`는 용량이 크고 원본이므로 Git에 올리지 않는다(`.gitignore`). 다운로드 기록(아래)만 Git에 올린다.

```text
data/raw/
  crosswalk/            # R1 전국횡단보도표준데이터
  admin_boundary/       # R2 admdongkor
  population_65/        # R3 행안부 고령 인구
  crash_zone/           # R4 노인 보행사고 다발지역 (연도별 파일)
  protect_zone/         # O1 노인장애인보호구역
  senior_center/        # O2 마을회관및경로당
  market/               # O3 전통시장
  hospital/             # O4 병원 (P2)
  download_log.csv      # 다운로드 기록 (Git에 올림)
```

**다운로드 기록(`download_log.csv`)** — 파일 하나를 내려받을 때마다 한 줄을 추가한다. 나중에 “어느 시점의 데이터로 분석했는가”를 증명하는 데 쓴다.

```csv
id,file,source_url,downloaded_at,source_modified,row_count,encoding,by
R1,crosswalk/전국횡단보도표준데이터.csv,https://www.data.go.kr/data/15028201/standard.do,2026-10-24,2025-07-10,,cp949,이름
```

`source_modified`는 데이터 페이지에 표시된 수정일이다. `encoding`과 `row_count`는 내려받은 뒤 직접 확인해 채운다.

## 2. 한눈에 보기

필수 4종을 표의 순서대로 먼저 받고, 선택은 그 다음이다. 순서는 게이트 A→B→C 순이다(5장). "형식"은 데이터 페이지에서 확인한 표기이고, 다운로드에 로그인·활용신청이 필요한지는 페이지에서 직접 확인해야 한다.

| 순서 | 데이터 | 형식 | 저장 폴더 | 용도 |
| --- | --- | --- | --- | --- |
| 1 | **R1** [전국횡단보도표준데이터](https://www.data.go.kr/data/15028201/standard.do?recommendDataYn=Y) | CSV, API | `crosswalk/` | 핵심 입력(연장, 녹색신호시간, 좌표) |
| 2 | **R3** [행정동별 고령 인구현황(행안부)](https://jumin.mois.go.kr/etcStatOldAge.do) | CSV, XLSX | `population_65/` | 65세 이상 비율(거주 노출) |
| 3 | **R2** [admdongkor 읍면동 경계](https://github.com/vuski/admdongkor) | GeoJSON, parquet | `admin_boundary/` | 횡단보도를 읍면동에 배정 |
| 4 | **R4** [노인 보행사고 다발지역 API](https://data.go.kr/en/data/15057666/openapi.do) | Open API(인증키) | `crash_zone/` | 사고 노출 플래그 + 검증(연도 분할) |
| 5 | **O2** [전국마을회관및경로당표준데이터](https://www.data.go.kr/dcat/metadata/15114136) | 페이지 확인 | `senior_center/` | 경로당 반경 노출 |
| 6 | **O1** [전국노인장애인보호구역표준데이터](https://www.data.go.kr/data/15034532/standard.do) | CSV, API | `protect_zone/` | 보호구역 반경 노출 |
| 7 | **O3** [전국전통시장표준데이터](https://www.data.go.kr/data/15012894/standard.do) | CSV, API | `market/` | 전통시장 반경 노출 |
| 8 | **O4** [HIRA 병원정보서비스](https://www.data.go.kr/data/15001698/openapi.do) | Open API(인증키) | `hospital/` | 병원 반경 노출(P2, 좌표 필드 먼저 확인) |

**지금 받지 않아도 되는 것:** [전국신호등표준데이터](https://www.data.go.kr/data/15028198/standard.do)(보행신호 시간 필드 없음, 신호 주기 교차 확인용)와 [SGIS 격자 통계](https://www.data.go.kr/data/15141768/fileData.do)(연령별 인구 포함 여부 미확인). 시간이 남을 때만 받는다.

## 3. 필수 데이터 4종

네 가지 중 하나라도 쓸 수 없으면 지도 데모가 성립하지 않는다. 아래 체크박스가 모두 채워진 것을 “완료”로 본다. 페이지에서 답을 찾지 못했으면 빈칸으로 두지 말고 “찾지 못함”이라고 적는다.

### R1 전국횡단보도표준데이터

**가져오는 법:** [데이터 페이지](https://www.data.go.kr/data/15028201/standard.do?recommendDataYn=Y)에서 CSV 또는 API로 받는다. 페이지 안내에 그리드 다운로드는 5만 행이 한계라고 되어 있어 API가 권장된다. 받은 파일의 행 수가 5만 행에서 잘렸는지 반드시 확인한다. 페이지 기준 필드 25개, 반기 갱신, 수정일 2025-07-10.

- [ ] 전체 행 수와 칼럼명 전부(25개인지)
- [ ] 인코딩(utf-8-sig / cp949)
- [ ] 시도명에 “부산”이 들어간 행 수와 시군구별 행 수
- [ ] 횡단보도연장·녹색신호시간·적색신호시간·위도·경도의 입력률(비어 있지 않은 비율, 0 초과 비율)
- [ ] **녹색신호시간의 단위와 정의**(점멸 시간을 포함하는가). 페이지에는 항목명만 있고 정의가 없다. 데이터 제공 기관에 문의하거나 표준 정의서를 찾아 출처와 함께 적는다
- [ ] SH가 준 `check_crosswalk_data.py`를 돌린 출력(부산, 속도 1.0/0.8/0.7 부족 비율) 첨부

**알려진 주의:** 칼럼명은 페이지 요약 기준이라 실제 파일과 다를 수 있다. 이 데이터에는 읍면동 정보가 없고 시도·시군구와 좌표뿐이라 좌표 입력률이 특히 중요하다.

### R3 행정동별 고령 인구현황(행안부)

**가져오는 법:** [페이지](https://jumin.mois.go.kr/etcStatOldAge.do)에서 조회 단위를 읍면동까지 내리고 기준 월을 고른 뒤 CSV 또는 XLSX로 내려받는다. 월 단위 갱신이다. **기준 월은 하나로 고정**하고(가장 최근 월 권장) 다운로드 기록에 적는다.

- [ ] 전국 읍면동을 한 파일로 받을 수 있는지. 안 된다면 시도별로 나눠 받아 합친 방법과 파일 수를 기록
- [ ] 칼럼명 전부, 행정기관 코드 칼럼의 유무와 자리수
- [ ] 65세 이상(남·여·전체)와 **총인구** 필드 유무. 페이지에 비율 항목은 없어 총인구로 직접 계산해야 한다. 총인구가 없으면 같은 사이트의 읍면동별 총인구 표를 찾아 보고(미확인)
- [ ] 시도·시군구 합계 행이 읍면동 행과 섞여 있는지 (서울·부산 샘플 5곳을 눈으로 확인)

### R2 admdongkor 읍면동 경계

**가져오는 법:** [GitHub 저장소](https://github.com/vuski/admdongkor)에서 최신 버전(확인 시점 ver20260701)의 WGS84 GeoJSON을 받는다. 같은 저장소에 EPSG:5179 parquet도 있다. 정확한 파일명은 README에서 확인한다. 라이선스는 CC BY 4.0이라 발표·화면에 출처를 표기해야 하므로 저장소 주소와 버전을 기록해 둔다.

- [ ] 속성 칼럼명 전부(8자리 `adm_cd`, 10자리 `adm_cd2` 등)와 행 수
- [ ] 좌표계가 WGS84인지
- [ ] **게이트 C:** R3의 코드와 경계 코드가 몇 %나 일치하는지, 8자리·10자리 중 어느 쪽과 맞는지(방법은 5장)

**알려진 주의:** 저장소가 일부 지역의 경계가 실제와 맞지 않을 수 있다고 안내한다. 2026-07-01 시도·시군구 코드 개편이 경계에는 반영되어 있어, R3 기준 월이 그보다 이르면 코드가 어긋날 수 있다.

### R4 노인 보행사고 다발지역 API

**가져오는 법:** [데이터 페이지](https://data.go.kr/en/data/15057666/openapi.do)에서 활용신청을 한다(페이지 기준 자동 승인, 개발 계정 호출 한도 10,000건). 발급받은 인증키로 호출하며 연도는 `searchYearCd` 파라미터로 지정한다. **연도별 응답을 각각 파일로 저장**한다(`crash_zone_<연도>.json`). 과거 연도는 노출 플래그에, 최근 연도는 검증에 따로 쓰기 때문이다. 필드 정보가 빠진 [행안부 버전](https://data.go.kr/catalog/15152407/openapi.json)은 대체용으로만 본다.

- [ ] 요청 파라미터 전체(시도·시군구 코드를 반드시 넣어야 하는지, 전국을 한 번에 받을 수 있는지)
- [ ] **어느 연도부터 어느 연도까지 응답이 오는지**(연도별로 한 번씩 호출해 연도별 응답 건수 표로 기록). 페이지 샘플은 2015년 값이었다
- [ ] 응답 필드: 폴리곤 좌표 형식, 사고·사망·중상 건수, 사고 원인을 나타내는 필드가 있는지
- [ ] 인증키는 문서·코드·Git에 적지 않고 환경변수로만 쓴다

## 4. 선택 데이터 (노출용 4종)

노출 플래그(횡단보도 반경 안에 시설이 있는지)를 만드는 데이터다. 하나라도 못 받으면 그 플래그만 빠지고 MVP는 진행된다(게이트 D). 아래 "페이지 요약"은 데이터 페이지에서 읽은 내용이며 실제 파일은 아직 확인하지 않았다.

### O2 전국마을회관및경로당표준데이터

**가져오는 법:** [메타데이터 페이지](https://www.data.go.kr/dcat/metadata/15114136)에서 같은 데이터의 다운로드 페이지를 찾아 받는다. 페이지 요약: 시설명, 시설유형, 도로명·지번주소, 위도, 경도, 영업상태, 건립일자, 건물면적, 관리기관명, 연 1회 갱신, 수정일 2026-07-02. 지자체가 등록하는 방식이라 누락이 있을 수 있다.

- [ ] 전체 행 수, 칼럼명, 인코딩
- [ ] 시설유형 값의 종류와 건수(경로당과 마을회관이 섞여 있음)
- [ ] 위도·경도 입력률, 영업상태 값(폐업 포함 여부)
- [ ] **누락 점검:** 시군구별 행 수 표. 0건이거나 비정상적으로 적은 시군구를 적는다
- [ ] **교차 확인:** [부산 강서구 경로당 현황](https://www.data.go.kr/data/15048645/fileData.do)은 168개소로 공개돼 있다. 전국 데이터의 강서구 경로당 행 수가 이와 얼마나 차이 나는지 적는다

### O1 전국노인장애인보호구역표준데이터

**가져오는 법:** [데이터 페이지](https://www.data.go.kr/data/15034532/standard.do)에서 CSV 또는 API. 페이지 요약: 위경도, 제한속도, 도로폭, CCTV, 반기 갱신, 수정일 2026-06-16.

- [ ] 행 수, 칼럼명, 인코딩
- [ ] 위도·경도 입력률. 좌표가 보호구역의 대표 한 점인지, 구간 정보(시작·끝)가 따로 있는지 기록(반경 계산 방식이 달라진다)
- [ ] 보호구역 종류·지정일 칼럼이 없다는 것 확인(있으면 기록)

### O3 전국전통시장표준데이터

**가져오는 법:** [데이터 페이지](https://www.data.go.kr/data/15012894/standard.do)에서 CSV 또는 API. 페이지 요약: 시장명, 시장유형, 도로명·지번주소, 위도, 경도, 점포수 등 15개 필드, 연 1회 갱신, 수정일 2025-11-26.

- [ ] 행 수, 칼럼명, 인코딩
- [ ] 위도·경도 입력률
- [ ] 시군구별 행 수 표

### O4 HIRA 병원정보서비스 (P2, 좌표 확인 후에만)

**가져오는 법:** [데이터 페이지](https://www.data.go.kr/data/15001698/openapi.do)에서 활용신청(개발 계정은 페이지 기준 자동 승인, 일 10,000건). 인증키는 O4와 R4 모두 문서·Git에 적지 않는다.

- [ ] **응답 필드에 좌표(위도·경도)가 있는지.** 없으면 O4는 여기서 멈추고 SH에게 알린다(주소를 좌표로 바꾸는 작업은 하지 않는다)
- [ ] 좌표가 있다면 병원 종류(종합병원·병원·의원 등)를 구분하는 필드가 있는지. 의원까지 모두 포함하면 수가 매우 많아 반경 노출이 의미를 잃을 수 있다(우려, 확인 필요)
- [ ] 전국을 받는 데 필요한 호출 수와 일일 한도

## 5. 확인 결과 보고와 게이트

데이터를 받는 대로 아래 양식을 채워 SH에게 보낸다. 게이트는 A→B→C→D 순서이고, 막히면 다음 단계로 넘어가기 전에 바로 알린다.

| 게이트 | 대상 | 통과 기준 | 통과 못 하면 |
| --- | --- | --- | --- |
| A | R1 | 부산 행 수와 연장·녹색신호시간·좌표 입력률을 확인하고, 녹색신호시간의 정의를 확인했거나 “찾지 못함”으로 기록함 | 일반 기준(1.0m/s) 부족 비율이 40% 초과면 점멸 제외 등 정의 문제를, 1% 미만이면 자동 입력을 의심하는 경고 신호다. 발견하면 바로 SH에게 알린다 |
| B | R3 | 전국 읍면동을 확보하고 총인구가 있거나 총인구를 구할 방법을 찾음 | 시도별 분할 방법이나 총인구 부재를 적어 보고 |
| C | R2 + R3 | 코드 일치율(%)을 측정해 보고. 기준선은 결과를 본 뒤 SH가 정한다 | 일치율과 불일치 상위 사유(예: 코드 자리수, 신설·폐지 지역)를 보고 |
| D | R4, O1\~O4 | 데이터별 좌표 입력률, 시군구별 행 수, R4의 연도 범위를 보고 | 못 받는 데이터는 그 노출 플래그만 제외한다 |

**게이트 C 확인 예시** — 칼럼명은 실제 파일에 맞게 고친다. 경계 파일의 8자리와 10자리 코드 둘 다 해 본다.

```python
import pandas as pd, geopandas as gpd

b = gpd.read_file("data/raw/admin_boundary/<GeoJSON 파일>")
p = pd.read_csv("data/raw/population_65/<CSV 파일>", dtype=str, encoding="cp949")  # 실패하면 utf-8-sig

pop_codes = set(p["<행정기관코드 칼럼>"])
for col in ("adm_cd", "adm_cd2"):
    print(col, len(set(b[col]) & pop_codes) / len(pop_codes))
```

## 6. 주의사항과 막혔을 때

**급한 순서는 R1 → R3 → R2다.** 이 셋으로 게이트 A·B·C가 결정된다. PRD 일정에서는 10/20 안에 확인하기로 했지만 아직 결과가 없으므로, 이 셋의 보고를 가장 먼저 한다. R4와 선택 4종은 그 다음이다.

**하지 말 것**

- 원본 파일을 엑셀로 열어 저장하기. 인코딩, 숫자 형식, 앞자리 0이 바뀔 수 있다.
- 비공식 사이트의 사본이나 민간이 가공한 데이터로 대신하기. 출처가 다르면 기준 시점과 정의가 달라진다. 없으면 없다고 보고한다.
- 인증키를 문서, 채팅, Git, 스크린샷에 그대로 남기기.
- 주소를 좌표로 바꾸는 지오코딩이나 결측 채우기를 임의로 하기. 필요하면 SH와 먼저 정한다.

**알아 둘 것**

- 분석에 필요한 칼럼만 쓴다. 경로당 등 시설 데이터에는 전화번호 같은 칼럼이 있을 수 있어, 정제 결과·산출물에는 넣지 않는다.
- 다운로드에 로그인이나 활용신청이 필요할 수 있다. 필요 여부와 승인 대기 시간은 페이지에서 직접 확인해 기록한다.
- 각 데이터의 이용허락범위(라이선스)는 아직 확인하지 못했다. 데이터 페이지에서 찾아 `download_log.csv`에 추가 열로 적는다. admdongkor는 CC BY 4.0이다.

**막혔을 때:** 사이트 점검·접속 불가, 다운로드 한도(R1의 5만 행), 인증키 승인 대기 등은 “무엇을 어느 URL에서 어떻게 시도했고 어떤 메시지가 나왔는지”를 그대로 적어 SH에게 보낸다. 해결 방법을 혹로 찾아 대체 데이터를 쓰기 전에 먼저 알린다.
