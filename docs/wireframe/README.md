# 와이어프레임 (PRD 10장 기준, 데스크톱 1440×900)

| 파일 | 화면 | 관련 기능 |
| --- | --- | --- |
| `01-main.svg` | 메인: 필터·속도 슬라이더·레이어 / 지도 / 사분면·상위 N | F4~F7, F9~F11 |
| `02-region-detail.svg` | 읍면동 선택 시 상세 패널 + 횡단보도 목록 | F5, F7 |
| `03-validation.svg` | 검증 V1~V5 | F8 |

- 파란 배지(`F6` 등)는 PRD 6장의 기능 ID. `P1`은 시간이 남을 때만.
- 숫자·지역명은 모두 자리표시(`00`, `OO시`)이며 실제 결과가 아님.
- 색은 단일 계열(파랑) 명도로 짧음 비율을 표현(색맹 대응), 표본 부족은 빗금 회색, 후보 횡단보도는 주황 마름모.
- 표시 문구는 PRD 3장 표현 원칙을 따름("기준식보다 짧음", "점검 우선순위 후보").

## 참고한 공공 지도 서비스 패턴
확인일 2026-10-26. 브라우저로 직접 본 것은 SGIS 청년통계지도·업종통계지도 화면뿐이며, 다른 서비스는 구조를 직접 확인하지 못했다.

| 패턴 | SGIS에서 본 것 | 반영 |
| --- | --- | --- |
| 좌측 세로 메뉴로 주제·필터 선택 | 인구·가구, 주거·이동 등 아이콘 메뉴 | 좌측 필터 패널(지역·속도·레이어) |
| 지도 위에 요약 지표 카드 | 청년 인구 등 KPI 카드와 연도별 차트 | 지도 상단 KPI 4칸 |
| 지도 우측 컨트롤 묶음 | 확대·축소, 지도유형, 초기화 | 우측 줌/홈/배경지도 버튼 |
| 상단 공유·저장·보고서 | 공유하기, 저장하기, 보고서보기 | CSV 저장(F12, P1) |
| 지도와 차트가 연동 | 업종통계지도의 막대·증감 차트 | 사분면·목록·지도 연동 강조 |

## 재생성
`scratchpad`의 생성 스크립트는 repo에 없다. SVG를 직접 수정하거나, 필요하면 스크립트를 `scripts/`로 옮긴다.
