# 007. 데이터 선택 이유

- 날짜: 2026-10-27 (조사 기록) / 관련: PRD 4장, `docs/data-collection-guide.md`
- 상태: **데이터 페이지로 확인. 실제 파일은 아직 받지 않음(게이트 A~D)**

공통 원칙: 전국 범위, 공식 기관이 정기적으로 갱신, 무료 공개, 출처가 분명한 자료만 쓴다. 비공식 사본이나 민간 가공 자료로 대체하지 않는다(수집 가이드 6장).

| 데이터 | 왜 이 데이터인가 | 확인한 사실 | 출처 |
| --- | --- | --- | --- |
| 전국횡단보도표준데이터 (필수) | 전국 횡단보도의 **연장과 녹색신호시간을 함께** 담은 유일한 공개 자료. 기준식 비교에 둘 다 필요하다 | 소관 국토교통부·경찰청, 제공 지방자치단체, 반기 갱신, 수정일 2025-07-10, 25개 항목(위도·경도·횡단보도연장·녹색신호시간·적색신호시간 등). 항목 정의·단위는 페이지에 없음(002) | <https://www.data.go.kr/data/15028201/standard.do> (2026-10-27 열람) |
| 행정안전부 고령인구현황 (필수) | 읍면동 단위 65세 이상 인구와 전체 인구를 **매월** 공식 공개 | 주민등록 기준, 매월 말일 기준·다음 달 1일 공개, 2008년 이후, 항목 전체·65세 이상(남·여) | <https://jumin.mois.go.kr/etcStatOldAge.do> (2026-10-27 열람) |
| admdongkor 읍면동 경계 (필수) | 행정동 경계를 **공개 라이선스로 바로 받을 수 있는** 자료. 통계청 SGIS 경계를 바탕으로 변경 이력을 반영해 연 4회 갱신 | 데이터 CC BY 4.0(원자료 SGIS 공공누리 제1유형, 출처표시 의무 유지), GeoJSON은 WGS84. 저장소가 일부 경계 부정확 가능성을 안내 | <https://github.com/vuski/admdongkor> (2026-10-27 열람) |
| 노인 보행사고 다발지역 API (필수) | 노인 보행사고가 실제로 모인 곳을 공식 기준으로 제공. 노출과 검증 모두에 쓴다 | 도로교통공단, 65세 이상 기준, 연도별 조회, 이용 제한 없음. 2021년 선정 기준 변경(006) | <https://data.go.kr/en/data/15057666/openapi.do> (2026-10-27 열람) |
| 마을회관·경로당, 전통시장, 노인·장애인 보호구역 표준데이터 (선택) | 노인이 정기적으로 오가는 시설의 **좌표**를 전국 단위로 제공(005) | 수집 가이드의 페이지 요약 기준. 이번 조사에서 다시 열람하지 않음 | 수집 가이드 4장의 링크 |

## 대안과 쓰지 않은 이유
| 대안 | 쓰지 않은 이유 | 출처 |
| --- | --- | --- |
| 경계: SGIS 원본 | 신청 절차가 필요하고, admdongkor가 같은 원자료를 이력과 함께 정리해 둠 | admdongkor README |
| 경계: 도로명주소지도·브이월드 | 더 정확할 수 있으나 가공 부담이 큼. admdongkor가 정확한 경계가 필요하면 이쪽을 확인하라고 안내하므로, 경계 오류가 의심되는 지역만 대조용으로 쓸 수 있음 | admdongkor README |
| 전국신호등표준데이터 | 보행신호 시간 필드가 없음. 신호 주기 교차 확인용으로만 남김 | PRD 4장 |
| 장래인구추계, 연령별 유동인구, 노인복지관 위치 | 시군구 이하 단위나 전국 자료를 찾지 못함 | PRD 4장 |
| SGIS 격자 통계 | 연령별 인구 포함 여부 미확인 | PRD 4장 |

## 아직 모르는 것
- 각 표준데이터의 이용허락범위(수집 가이드 6장, `download_log.csv`에 기록 예정).
- 실제 파일의 칼럼명, 인코딩, 입력률(게이트 A~D).
