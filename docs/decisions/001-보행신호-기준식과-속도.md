# 001. 보행신호 기준식과 보행속도 3종

- 날짜: 2026-10-27 (조사 기록) / 관련: PRD 3장, `config.yaml`(`entry_seconds`, `speeds_mps`)
- 상태: **공식 산정 방식은 2차 자료로 확인, 매뉴얼 원문은 미확인**

## 결정
필요시간을 `T_need(v) = 7 + L / v`로 계산하고, 보행속도 v는 **1.0 / 0.8 / 0.7 m/s 세 가지를 모두** 계산한다. 하나를 정답으로 고르지 않고 세 결과를 함께 보여준다(속도 민감도, V2).

## 왜 이 식인가
국내 보행신호 시간은 "보행진입시간 + 횡단보도 길이 ÷ 보행속도"로 정한다. 우리 식은 이 산정 방식을 그대로 옮긴 것이다.

| 항목 | 내용 | 출처 (확인 수준) |
| --- | --- | --- |
| 기본 산정 | 보행진입시간 7초 + 횡단보도 1m당 1초. 32m 횡단보도는 39초 | 서울시 교통정보 누리집, 「'신호등 속 과학' 횡단보도 보행신호시간 어떻게 정해지나」, 교통운영과, 수정일 2018-10-22 — <https://news.seoul.go.kr/traffic/archives/12356> (공식 페이지, 직접 열람) |
| 보행약자 기준 | 어린이·어르신·장애인이 많거나 보행 밀도가 높은 곳은 0.8m당 1초. 32m는 약 47초 | 위와 같음 (직접 열람) |
| 근거 매뉴얼 | 경찰청 「교통신호기 설치·관리 매뉴얼」이 보행신호 산정 방법을 제시. 일반 1.0 m/s, 보호구역 0.8 m/s(논문 작성 당시). 진입시간은 보통 7초, 인지반응을 고려해 최소 4초 이상 | 한음·조혜림·문성철·윤성범·박순용 (2020). 노인보호구역 보행자녹색시간 산정을 위한 보행속도 기준 개선. 한국ITS학회논문지 19(4), 45–54. doi:10.12815/kits.2020.19.4.45 — <https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002621242> (학술, 초록 열람. 매뉴얼 내용은 논문이 인용한 것) |

- 7초는 "보행진입시간", 즉 신호가 바뀐 뒤 보행자가 반응해 횡단을 시작하기까지의 시간이다. 서울시 페이지는 7초를 정한 근거를 설명하지 않는다.
- 같은 L에 대해 v가 작을수록 필요시간이 길어진다. 30m 횡단보도라면 1.0 → 37초, 0.8 → 44.5초, 0.7 → 약 49.9초다.

## 왜 속도 세 가지인가
| 속도 | 의미 | 출처 (확인 수준) |
| --- | --- | --- |
| 1.0 m/s | 일반 기준 | 서울시 페이지(위), 한음 외(2020) |
| 0.8 m/s | 보행약자가 많은 곳(서울시), 이전 보호구역 기준 | 서울시 페이지(위), 한음 외(2020) |
| 0.7 m/s | 현행 노인·어린이보호구역 기준(최대) | 서울시 교통정보 누리집, 「교통약자 누구나! 천천히 안심하고 건너세요… 서울시·서울경찰청, 횡단보도 보행신호 시간 연장 확대」, 수정일 2024-10-16 — <https://news.seoul.go.kr/traffic/archives/512963> (공식 페이지, 직접 열람). 경기일보 칼럼 「'보행신호시간' 개선의 필요성」(2023-11-30)은 2022년 경찰청이 교통약자 보행속도 기준을 0.7 m/s로 개정했다고 씀 — <https://kyeonggi.com/article/20231129580350> (언론, 직접 열람) |

**실측으로 본 근거.** 한음 외(2020)의 조사(초록)에서 평균 보행속도는 일반인 1.29 m/s, 노인 1.13 m/s였지만, **느린 쪽 15퍼센타일**은 일반인 1.01 m/s, 노인 0.85 m/s, 지팡이·휠체어를 쓰는 노인은 0.73 m/s였다.
- 신호 설계는 평균이 아니라 느린 보행자(대개 15퍼센타일)를 기준으로 삼는다. 평균으로 맞추면 절반 가까운 사람이 시간 안에 건너지 못하기 때문이다.
- 그래서 일반 1.0(일반인 15퍼센타일 1.01과 비슷), 0.8(노인 15퍼센타일 0.85에 가까움), 0.7(보조기구 사용 노인 0.73에 가까움)은 각각 다른 보행자 집단에 대응한다. 세 값을 함께 보는 이유다.

**해외 기준과 비교 (참고).** 미국 MUTCD 4E.06은 보행 횡단 시간에 3.5 ft/s(약 1.07 m/s)를 쓰고, 느린 보행자가 자주 이용하면 더 낮은 속도를 고려하도록 권한다. Gates·Noyce 외(2006)는 65세 이상 비율이 높을수록 낮은 속도를 권하고, 거의 모두가 65세 이상인 곳은 2.9 ft/s(약 0.88 m/s)를 권했다.
- MUTCD 4E.06 조문(델라웨어 주 채택본) — <https://regulations.justia.com/states/delaware/title-2/2000/2400/2402/part-4/chapter-4e/section-4e-06> (공식 조문의 주 채택본, 검색 요약 기준)
- Gates, Noyce 외 (2006). Recommended Walking Speeds for Pedestrian Clearance Timing. TRB — <https://files.topslab.wisc.edu/publications/2006/noyce_2006_1826.pdf> (학술, 검색 요약 기준)

- PRD 1장의 "1,000곳", "자동연장 221곳", 제주 139곳, 부산 111곳 수치는 이번 조사에서 **원문을 찾지 못했다**. 발표 전에 다시 확인해야 한다.

## 우리가 단순화한 것
- 진입시간은 매뉴얼상 4~7초 범위로 조정될 수 있지만 7초로 고정했다(`config.yaml`).
- 보행자 작동신호기, 보행신호 자동연장, 교통섬(두 번에 나눠 건너기)은 반영하지 않았다. 이런 횡단보도는 기록값과 기준식의 차이가 다르게 나타날 수 있다.

## 아직 모르는 것
- 경찰청 매뉴얼 **현행판 원문**과 0.8 → 0.7 개정 시점. 경찰청 공지(「횡단보도 보행속도 기준 개선」 연구용역 2019.5~12)는 검색 결과로만 확인했고 본문을 열지 못했다 — <https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1001&q_bbscttSn=20201201084730717>
- 7초의 산정 근거.

## 바꿀 조건
매뉴얼 원문에서 진입시간이나 속도 기준이 다르게 확인되면 `config.yaml`만 고치고 파이프라인을 다시 돌린다.
