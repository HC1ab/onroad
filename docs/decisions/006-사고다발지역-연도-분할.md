# 006. 노인 보행사고 다발지역의 연도 분할

- 날짜: 2026-10-27 (조사 기록) / 관련: PRD 7장 V3, 12장 리스크, 이슈 #4(D1), #10(D7)
- 상태: **근거 확인. 단, 선정 기준이 바뀐 연도가 있어 분할 연도를 다시 정해야 함 (팀 결정 필요)**

## 결정 (PRD)
과거 연도 다발지역은 후보를 고르는 노출 플래그로, 최근 연도 다발지역은 후보가 실제 사고 지점과 겹치는지 확인하는 검증(V3)으로만 쓴다.

## 왜 나누나
같은 사고 자료로 후보를 고르고 그 자료로 다시 검증하면, 겹치는 게 당연해서 검증이 의미가 없다(순환). 연도를 나누면 "과거 정보로 고른 후보가 그 뒤의 사고 지점과 겹치는가"를 볼 수 있다.

## 자료 정보
도로교통공단 보행노인 사고다발지역 정보 API — <https://data.go.kr/en/data/15057666/openapi.do> (공식, 2026-10-27 열람)
- 노인: 65세 이상 보행자
- 연도는 `searchYearCd`로 지정, 다발지역 폴리곤과 사고·사망·중상 건수를 준다
- 이용허락범위: 제한 없음, 무료, 자동 승인

## 새로 확인한 문제: 2021년에 선정 기준이 바뀜
| 기간 | 대상 사고 | 다발지역 조건 |
| --- | --- | --- |
| 2012~2020 | 65세 이상 보행자 사상 사고 | 반경 200m 안 3건 이상 (사망 포함 시 2건 이상) |
| 2021~ | 최근 3년 65세 이상 보행자 **사망·중상** 사고 | 반경 **100m** 안 **5건** 이상 |

(위 API 페이지의 참고 문서 설명 기준)

- 기준이 다르면 다발지역의 크기(200m ↔ 100m)와 수가 달라진다. 과거를 2020년 이전, 최근을 2021년 이후로 나누면 겹침 비율의 차이가 **기준 변경 때문인지** 구분할 수 없다.
- 2021년 이후 기준은 "최근 3년" 누적이라, 연속한 연도끼리는 같은 사고가 겹쳐 들어갈 수 있다. 과거·최근 연도 사이에 3년 이상 간격을 두거나, 겹침을 감안해야 한다.

## 제안 (팀 결정 필요)
1. D1에서 연도별 응답 건수를 먼저 확인한다(게이트 D).
2. 가능하면 **같은 기준 안에서** 나눈다(예: 2021~2022를 플래그, 2024~2025를 검증. 실제 제공 연도에 맞춰 조정).
3. 같은 기준으로 나눌 연도가 부족하면 다발지역을 노출 플래그에서 빼고 검증용으로만 쓴다(PRD 12장 대응과 같음).
