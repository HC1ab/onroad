# 008. 분석 범위를 부산으로 확정하고 기본 파이프라인 v1을 정한다

- 날짜: 2026-10-30 (팀 확정) / 관련: PRD 3·7·12장, `decisions/002`·`004`·`005`·`006`·`007`
- 상태: **팀 확정. 단, 보행시간 필드의 정의(녹색 + 점멸)는 미확인 가정이다**

## 결정
분석 범위를 R1 전국횡단보도표준데이터(녹색신호시간이 기록된 17개 시군구)에서 **부산광역시 신호등 설치 횡단보도 엑셀**(2026-08-01 기준, 3,815곳)로 바꾼다. 실측(V1)과 V5는 이번 범위에서 제외한다.

## 왜 부산인가
- R1은 58,841행 중 녹색신호시간이 0보다 큰 곳이 8,263곳(14%)이고 17개 시군구에 몰려 있다. 부산·대구는 R1에 행이 없다. (팀 계산, 2026-10-29 수집본)
- 부산 엑셀은 3,815곳 중 3,751곳(98%)에 길이·보행시간·좌표가 모두 있고, 읍면동 경계에 배정되는 3,726곳이 분석 대상이다.
- 부산은 출장소가 없고, 읍면동 경계(R2)와 고령 인구(R3)가 206개로 같으며 코드가 모두 일치한다.

## 가정 (확인 전)
`보행시간` = 실제 운영 중인 보행신호 전체 시간(녹색 + 점멸)이다. 경찰청 편람에서 기준식 `7 + L/v`의 결과가 녹색 + 녹색점멸 시간이므로 같은 의미로 비교한다. 모든 수치는 "gap>0 비율, 정의 미확정"으로 쓴다.
부산 보행시간은 대부분 기준식 값과 같다(분석 3,726곳 중 1.0m/s 기준식 3,089곳, 0.7m/s 기준식 346곳, 0.8m/s 2곳, 그 외 289곳). 따라서 결과는 "노인 기준(0.7m/s)을 반영한 곳과 아닌 곳"으로 읽는 것이 정확하다.

## 파이프라인
| 단계 | 규칙 |
| --- | --- |
| 수집 | 부산 엑셀 첫 시트, R2, R3, R4, O1, O2, O3. 원본 그대로 저장, `download_log.csv` 기록 |
| 정제 | 길이·보행시간·좌표 없는 행, 중복, 이상치 제외(3,815 → 3,751). 사유별 건수표. 보행시간은 소수점 그대로 |
| 위치 배정 | 좌표 → 읍면동 `adm_cd2`. 배정 실패 25곳 제외(3,726). 경계 밖 거리는 표에 남기고 자동 보정하지 않음 |
| 판정 | 속도 1.0·0.8·0.7m/s로 `T_need = 7 + L/v`, `gap = T_need − 보행시간`. 보행시간이 어느 기준식과 같은지 분류 |
| 집계 | 동별 gap>0 비율, 65세 이상 비율, 부산 중앙값 기준 사분면. 분석 가능 5곳 미만 동 회색 |
| 노출·후보 | 플래그 3종, 반경 300m(민감도 200·500m). 각 속도에서 gap>0 이면서 플래그 1개 이상이면 그 속도의 후보(계약: 속도·반경별 `is_candidate`) |
| 검증 | V2 속도 민감도, V3 사고다발지역 연관성(2021~2025), V4 축 독립성·이미 조정됐나 |

## 노출 플래그 3종
| 플래그 | 기준 | 부산 횡단보도 중 해당(300m) |
| --- | --- | ---: |
| 노인보호구역 | O1 `장소유형코드` 1·01만 | 6% |
| 전통시장 | O3 부산 | 18% |
| 경로당 밀집 | O2 영업 중 경로당·마을회관및경로당, 반경 안 개수가 부산 상위 25%(현재 4곳 이상) | 29% |

원칙: 플래그 하나가 부산 횡단보도의 절반 이상에 붙으면 그대로 쓰지 않는다. 경로당 "있다/없다"는 반경 300m에서 76%에 붙어 구분력이 없어 밀집도로 바꿨고, 마을회관 단독은 노인 전용 시설이 아니고 4%에만 붙어 제외한다.

## 사고다발지역은 플래그에서 제외, V3 검증 전용
부산 2024~25년 다발지역 95곳 중 59곳(62%)이 2021~23년 다발지역과 폴리곤이 겹친다. 연도를 나눠도 같은 장소가 되풀이되어 "같은 자료로 고르고 같은 자료로 검증하는 순환"을 막지 못한다. 그래서 후보 선정에는 쓰지 않고, V3 검증에만 2021~2025년 부산 218곳 전체를 쓴다. 이는 PRD 12장 리스크 표의 대안(사고다발지역을 확인용으로만 사용)과 같은 방향이며, 이유는 연도 범위 부족이 아니라 연도 간 장소 겹침이다.

## 구현 시 확인한 수치 (분석 3,726곳, 정의 미확정)
- gap>0 비율: 1.0m/s 3.06%, 0.8m/s 87.49%, 0.7m/s 87.90%. 0.7m/s에서는 대부분이 해당하므로 후보는 사실상 "시설 근처 횡단보도"와 겹친다.
- 보행시간이 0.7m/s 기준식과 정확히 같은 346곳은 부동소수 허용오차(1e-6초) 안에서 "짧지 않음"으로 처리한다.
- 동 비교에서 분석 가능 5곳 미만(low_sample)은 38개 동(5곳 미만 34, 횡단보도 없음 4).

## 한계 (화면·발표에 표시)
1. 결과는 부산의 기록된 보행시간 기준이다. 실제 운영 시간과 같은지는 확인 전이다.
2. 부산 보행시간의 대부분이 기준식 값이어서, gap은 횡단보도 길이와 적용 속도에 크게 좌우된다.
3. 읍면동 비율은 개별 횡단보도 이용자의 구성을 뜻하지 않는다(생태학적 오류).
4. 현장 실측(V1)이 없어 보행시간 정의를 확정하지 못했다.
5. V3의 무작위 비교는 보행량·도로 규모를 통제하지 않는다. 후보가 시설 근처에 몰려 있어 위치 영향이 섞인다.
