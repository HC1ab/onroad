# 003. 고령 기준 65세와 읍면동 단위

- 날짜: 2026-10-27 (조사 기록) / 관련: PRD 3장 사분면, 4장 데이터
- 상태: **근거 확인 (데이터 제공 형태와 통계 관행), 일부는 팀 판단**

## 결정
거주 노출은 **읍면동별 65세 이상 인구 비율**로 본다.

## 왜 65세 이상인가
| 이유 | 출처 (확인 수준) |
| --- | --- |
| 쓰려는 인구 통계가 **65세 이상**과 전체 인구를 읍면동 단위로 제공한다. 75세 이상 같은 다른 구간은 이 표에 없다 | 행정안전부 주민등록 인구통계, 고령인구현황 — <https://jumin.mois.go.kr/etcStatOldAge.do> (공식, 2026-10-27 열람: 항목 전체·남·여, 65세 이상 전체·남·여) |
| 검증에 쓰는 노인 보행사고 다발지역 자료도 **65세 이상** 보행자를 노인으로 정의한다. 두 데이터의 기준을 맞출 수 있다 | 공공데이터포털, 도로교통공단 보행노인 사고다발지역 API — <https://data.go.kr/en/data/15057666/openapi.do> (공식, 직접 열람) |
| 고령화 단계(고령화·고령·초고령사회)와 주요 복지 제도가 65세를 기준으로 쓴다. 다만 법률이 노인 연령을 하나로 정해 두지는 않았다 | 비즈한국 칼럼 — <https://bizhankook.com/articles/23030.html> (언론, 검색 요약 기준) |

- 대안: 75세 이상은 보행속도가 더 느린 집단이라 의미가 있지만, 읍면동 단위 공개 통계가 없어 쓰지 않는다.

## 왜 읍면동인가
| 이유 | 출처 (확인 수준) |
| --- | --- |
| 인구(행안부)와 경계(admdongkor)를 **같은 단위로 구할 수 있는 가장 작은 단위**다 | 행안부 고령인구현황(위), admdongkor — <https://github.com/vuski/admdongkor> (SGIS 행정동 경계 기반) |
| 서울시도 신호 연장 대상을 **동별 고령자 비율**로 골랐다. 행정 담당자에게 익숙한 단위다 | 서울시 교통정보 누리집, 수정일 2024-10-16 — <https://news.seoul.go.kr/traffic/archives/512963> (공식, 직접 열람) |

- 대안: 시군구는 너무 커서 지역 차이가 묻힌다. SGIS 격자 통계는 더 세밀하지만 연령별 인구 포함 여부를 확인하지 못했다(PRD 4장).

## 한계: 생태학적 오류
읍면동 평균은 그 동의 개별 횡단보도를 누가 쓰는지 알려주지 않는다. 집단 수준의 상관이 개인 수준과 다르거나 반대일 수 있다는 것은 오래 알려진 문제다.
- Robinson, W. S. (1950). Ecological Correlations and the Behavior of Individuals. *American Sociological Review*, 15(3), 351–357. (학술, 서지 정보는 2차 자료로 확인)

그래서 화면 하단에 이 한계를 항상 표시하고(F9), 횡단보도 단위 목록과 목적지 노출 플래그를 함께 보여준다(004, 005).
