# 002. 녹색신호시간 필드의 정의와 비교 방법

- 날짜: 2026-10-27 (조사 기록) / 관련: PRD 3·4장 게이트 A, V1 현장 실측, 이슈 #4, #11
- 상태: **미확인 — 게이트 A와 V1로 확정해야 함**

## 결정 (잠정)
전국횡단보도표준데이터의 `녹색신호시간`을 **보행신호 전체 시간(녹색 점등 + 녹색 점멸)** 으로 보고 기준식과 바로 비교한다. 정의가 확정되기 전까지 결과는 "부족"이 아니라 "기록값이 기준식보다 짧음(정의 미확정)"으로 표시한다.

## 왜 이렇게 가정하나
- 기준식 `7 + L/v`는 보행신호 **전체** 시간이다. 처음 진입시간(약 7초)은 녹색이 켜져 있고, 그 뒤 나머지 시간은 녹색이 깜빡인다(점멸). 즉 점멸 시간 = 전체 보행시간 − 처음 녹색 시간이다.
  - 서울시 교통정보 누리집, 수정일 2018-10-22 — <https://news.seoul.go.kr/traffic/archives/12356> (공식, 직접 열람: 진입 7초 + 1m당 1초)
  - 소셜포커스, 「보행자 신호등 시간 어떻게 계산할까?」 — <https://www.socialfocus.co.kr/news/articleView.html?idxno=11781> (언론, 검색 요약 기준: 4~7초 녹색 후 점멸)
- 그래서 필드가 전체 시간이면 비교가 맞고, **처음 녹색만 기록했다면** 거의 모든 횡단보도가 "짧음"으로 나온다.

## 확인한 것
- 공공데이터포털 데이터 페이지에는 항목명(녹색신호시간, 적색신호시간 등 25개)만 있고 **정의·단위·점멸 포함 여부가 없다**. 항목 정의는 「공공데이터 제공 표준」 문서(포털 자료실)에 있다고 안내한다 — <https://www.data.go.kr/data/15028201/standard.do> (공식, 2026-10-27 열람)
- 웹 검색으로는 정의를 찾지 못했다.

## 정의를 가리는 방법
1. **분포로 1차 판단 (게이트 A):** 1.0 m/s 기준 짧음 비율이 40%를 넘으면 처음 녹색만 기록했을 가능성, 1% 미만이면 기준식으로 자동 입력했을 가능성을 의심한다(PRD 4장).
2. **표준 정의서 확인:** 포털 자료실의 제공 표준 문서에서 항목 설명을 찾는다.
3. **현장 실측 (V1):** 부산 5~10곳에서 녹색과 점멸을 나눠 재고 기록값과 비교한다. 가장 확실한 방법이다.

## 결과별 처리
| 확인 결과 | 처리 |
| --- | --- |
| 전체 시간(점멸 포함) | 현재 식 그대로. `meta.green_def_status = includes_flash`, "정의 확정 전" 표시 해제 |
| 처음 녹색만 기록 | 기록값만으로는 전체 시간을 알 수 없다. 분석을 멈추고 팀이 대체 방법(신호등표준데이터 교차 확인 등)을 정한다 |
| 확인 불가 | 계속 "정의 미확정"으로 표시하고 한계 고지에 남긴다 |
