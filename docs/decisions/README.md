## 확인 수준 표기
- **공식, 직접 열람:** 정부·공공기관 페이지나 법령을 직접 열어 확인
- **학술:** 논문(초록 또는 본문)
- **언론:** 보도·칼럼. 원자료를 다시 확인해야 함
- **검색 요약 기준:** 웹 검색 결과 요약으로만 확인, 원문을 열지 못함
- 위키 문서는 근거로 쓰지 않는다.

## 형식
```markdown
# NNN. 제목
- 날짜 / 이슈: #번호
- 결정:
- 이유:
- 대안과 버린 이유:
```
