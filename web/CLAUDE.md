# C-web 구역 규칙

범위: F5~F7, F9~F12. Vite 정적 빌드 + MapLibre GL JS + 사분면 산점도. 서버·DB·로그인 없음.

- 데이터는 `public/data/`의 정적 파일만 읽는다. 파이프라인이 끝나기 전에는 `../contracts/samples/`로 개발한다.
- 표시 문구: "점검 우선순위 후보", "기록값이 기준식보다 짧음". "위험/위반/불법/늘려야 한다" 금지.
- 한계 고지(F9)와 데이터 출처 전체는 헤더 About 탭에 둔다. 지도 출처 표시(오른쪽 아래)에 admdongkor CC BY 4.0 등 데이터 출처를 항상 남긴다. 하단 바는 두지 않는다.
- 읍면동 평균의 한계(생태학적 오류), "플래그 없음은 노출 없음이 아님"을 화면에 적는다.
- `low_sample` 읍면동은 회색. 색은 단일 계열의 명도로 (색맹 대응). 발표는 데스크톱 기준, 모바일은 MVP 밖.
- 속도 슬라이더 변경 → 지도·사분면·목록이 2초 안에 갱신 (F6).
- 사용자 입력(녹색신호시간·현장 실측)은 그 브라우저에만 저장하고 CSV로 내보낸다. 서버로 보내지 않고, 화면에서는 "내 입력(검토 전)"으로 공식 결과와 나눠 보여준다.
